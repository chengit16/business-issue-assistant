# FastAPI 后端规范

适用于需要 Python 生态的业务 API，例如文档处理、知识检索或模型相关服务。配合[通用工程规范](../common/engineering.md)使用；仅需要普通业务 API 时也可选用 [NestJS 与 Fastify](nestjs-fastify.md)。

## 技术与模块

- 使用 Python、FastAPI、Pydantic 和 uv。使用 Ruff 完成格式与静态检查、mypy 做严格类型检查、pytest 测试，维护 `uv.lock`。公共函数声明参数和返回类型，外部未知值先校验，类型例外限定在具体边界。
- Router 和请求/响应 Schema 放在业务模块的 `api/`；`application/` 负责编排，`domain/` 维护领域规则，`infrastructure/` 实现存储与外部适配。应用入口装配依赖。模块只在有实际职责时拆分。
- 使用应用工厂集中装配 Router、Middleware、异常映射和生命周期。HTTP 的 `Depends`、Pydantic 请求模型和 ORM 模型均不进入领域规则。Worker 不导入 API 启动模块。

## HTTP 与契约

- Router 声明请求/响应模型、稳定的 OpenAPI `operation_id` 以及已知错误。对安全敏感请求拒绝合同以外的字段。区分 Pydantic 请求/响应、应用输入、领域对象、ORM 和任务事件。
- 以实际路由和 Schema 生成的 OpenAPI 为契约来源，变更后同步调用方类型和接口测试。错误在入口映射为通用规范约定的状态与错误信息。
- 只有确实使用异步 I/O 的调用链才使用异步方式；阻塞模型调用和重计算按实际并发与资源需求放到独立执行边界。

## 持久化与任务

- 需要关系型存储时使用 PostgreSQL、SQLAlchemy 和 Alembic。Session 在请求或任务的有限作用域内管理，写用例明确事务，Repository 不自行决定业务提交。唯一约束和必要的工作区条件落实到存储层。
- 通过版本化 Alembic 迁移变更结构；已进入共享历史的迁移不原地修改。检查空库和有代表性旧数据的升级，可回填时说明批次与失败恢复，应用启动不能代替正式迁移流程。
- 从单个 API 服务起步。需要后台导入、索引等可靠任务时，使用独立 Worker 和 Celery + Redis。载荷用版本与稳定 ID 引用数据，Worker 重新读取当前状态并去重；数据库保存业务任务事实，Redis 不作为唯一记录。
- 当业务数据与待投递任务必须一起持久化时，用同一事务写业务变更和待发送事件；事务提交后再投递，由 Worker 幂等消费。向量字段、对象存储、SSE 和外部模型适配按项目实际需求加入。

## Python 编写与扩展边界

- 模块、包、函数与变量用 `snake_case`，类和类型用 `PascalCase`，常量用 `UPPER_SNAKE_CASE`。用例表达动作与领域对象，避免万能 Manager 或 BaseService。生产函数和公开测试辅助函数完整标注类型，不用无范围的 `Any` 或 `type: ignore` 掩盖问题。
- 不使用可变默认参数，值对象优先不可变，有限状态采用明确类型；时间、SQL、分页、批量上限、事务失败和租户过滤遵循通用规范。ORM 对象不进入 HTTP、事件或任务载荷，延迟加载不得逃出事务。
- 跨域依赖公开接口或版本化事件，应用层依赖明确的存储能力而非私有基础设施。任务名作为稳定协议维护，不能用可变模块路径充当跨进程契约。
- 高风险迁移说明锁表、索引创建、回填批次、磁盘与恢复，先兼容性新增再切换调用方，独立版本移除旧结构；恢复方案通过隔离演练验证。
- 启用检索或模型能力时，结果与引用在服务端复核当前权限、资源版本和状态；无有效证据明确返回无证据结果，不伪造引用。模型 SDK 留在适配器，记录必要的模型版本与耗时。
- 启用 SSE 恢复时，契约明确事件 ID、序号、保留范围、回放上限、取消及最终事实；重连不得再次触发生成。文件导入校验类型、大小、编码和目标权限，失败清理临时对象，文件类型与回放时长由项目决定。

## 中文注释规范

必须同时执行[共用注释规则、阶段编号与长函数阈值](../common/comments.md)。

### 模块、公开接口与字段

手写 Python 模块必须以中文模块级 docstring 为第一条语句，`from __future__` 位于其后。简单包入口说明公开领域；领域、Application、Router、Repository/UoW、Adapter、Worker、SSE 与跨域基础设施还说明职责、依赖方向、写入权以及权限、事务和副作用边界。已有模块按实际修改范围补齐。

```python
"""编排工作区资源更新。

先核验可信上下文与预期版本，业务变更和出站事件在同一事务提交。
外部投递由提交后的任务处理，不在持锁期间调用远端服务。
"""
from __future__ import annotations
```

所有新增或实际修改的公开顶层类和函数必须提供中文 docstring。公开 Application 方法、Router 端点、Worker Task、SSE 服务、模型 Adapter 和解析器说明前置条件、返回事实、错误、幂等或事务要求。

Domain Protocol、Repository/UoW 在类型级说明方法集合的契约；个别方法存在额外约束时单独说明。具体 Adapter 的类级 docstring 解释 Session、锁、网络与副作用差异，不在实现方法中重复接口说明。

公开 Pydantic Schema 字段以 OpenAPI 为准，不直观的默认、省略、安全投影和兼容语义使用 `Field(description=...)`。Domain 值对象、Protocol 参数和回调说明状态、单位、时区、敏感级别及所有权语义。生成文件、第三方与协议固定文本保持原格式；Alembic 固定元数据保留，手写约束顺序、回填和不可逆步骤必须补中文说明。

### 各类文件最低说明

| 位置 | 必须说明 |
| --- | --- |
| Router | 公开端点 docstring；身份、工作区、协议映射和错误转换。 |
| Application | 公开用例和方法；可信上下文、授权顺序、事务、审计/Outbox 提交、幂等与副作用。 |
| Domain、Protocol | 公开类型；不变量、合法状态、拒绝原因、快照与可替换边界。 |
| Repository、UoW | 写入权、Session、工作区过滤、锁、唯一约束、版本与查询取舍。 |
| Worker | 事件版本、幂等键、有限重试、提交时机与死信或人工恢复。 |
| 外部 Adapter | 脱敏、超时、重试、能力差异与失败关闭。 |
| SSE | 序号、保留、回放上限、取消与最终事实。 |
| Migration、测试 | 回填与恢复，或被保护的业务行为和合成数据约束。 |

事务、版本、Outbox、SSE、模型或对象存储失败及历史回填须解释边界；线性流程使用连续编号的 `# 1. ...`、`# 2. ...`，共用阈值同时适用。

## 验证与交付

- 按[通用规模预警](../common/engineering.md#文件规模与职责预警)检查职责，运行项目配置的 Ruff、mypy 和 pytest，并核对 docstring、字段说明与阶段注释。
- 单元测试保护领域规则，应用测试保护授权与事务，集成测试验证真实数据库约束和迁移，契约测试覆盖 OpenAPI、错误码及已采用的事件/SSE。任务测试覆盖重投、乱序、失败状态和恢复；检索应用补充越权引用、旧版本晚到和无证据场景。
- 数据采用隔离、可清理的合成夹具，外部调用使用可控替身；稳定接口和错误码作为断言依据，真实供应商验收独立记录。自动化门禁与未覆盖的实际环境场景分别报告。
